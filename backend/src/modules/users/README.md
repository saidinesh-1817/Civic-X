# Users Module (Future Task)

This module will manage citizen profile data:
- User profile retrieval and updates
- Contact preferences
- Citizen history and activity overview

### Planned Structure:
- `users.controller.ts`: Handles HTTP request/response for user operations
- `users.service.ts`: User retrieval and profile update logic
- `users.route.ts`: Express router definitions (`/api/v1/users`)
- `users.schema.ts`: Zod validation schemas for user profile updates
